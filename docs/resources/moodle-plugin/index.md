The [Moodle Comparative Judgement plugin](https://marketplace.moodle.com/plugins/assignsubmission_comparativejudgement) is a free assignment submission plugin for Moodle that lets students and/or staff compare pairs of submissions, with the outcomes used to grade the assignment automatically and pushed into the gradebook.

- [Technical information](/resources/moodle-plugin/technical.html): how to install and configure the plugin
- [User guide](/resources/moodle-plugin/user-guide/): how to set up and run a comparative judgement assignment
- [Case studies](/resources/moodle-plugin/case-studies/): how teachers and lecturers use the plugin in their practice across different disciplines
