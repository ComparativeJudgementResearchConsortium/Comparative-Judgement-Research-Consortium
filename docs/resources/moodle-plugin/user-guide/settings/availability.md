title: Availability settings
---

{% include moodle-guide-draft.html %}

| Setting | Explanation |
|---|---|
| **Allow submissions from** | In a CJ assignment, this is when a student can submit their work to be judged. If you don't enable this setting, submissions can start immediately. |
| **Due date** | For CJ this is the deadline for submitting work to be judged. You will need to set a separate deadline directly with your students for completing their comparisons. Often teachers will arrange for the judging activity to be completed directly in class. |
| **Cut-off date** | This can be used in line with your local late submission policy to set a point past which submissions are no longer accepted (e.g. 4 hrs after due). This will not affect the judging activity, it will only close submissions. |
| **Remind to grade by** | Select this only if you want a reminder notification for marking. |
| **Always show description** | If this is disabled, the assignment description will only become visible on the “Allow submissions from” date |
