A comparative judgement assignment is a standard Moodle assignment with the Comparative judgement submission type switched on. These pages go through the settings you will need to consider.

## Comparative judgement settings

- [Availability](/resources/moodle-plugin/user-guide/settings/availability.html): when students can submit work to be judged
- [Submission types and comparisons](/resources/moodle-plugin/user-guide/settings/submission-types.html): switching on comparative judgement and setting how many comparisons are needed
- [Judging](/resources/moodle-plugin/user-guide/settings/judging.html): who judges, when judging starts and the instructions judges see
- [Files](/resources/moodle-plugin/user-guide/settings/files.html): the number, size and type of files students upload
- [Grade](/resources/moodle-plugin/user-guide/settings/grade.html): how grades are recorded

## Standard Moodle settings

- [Other Moodle assignment settings](/resources/moodle-plugin/user-guide/settings/other-moodle-settings.html): feedback, submission, group and notification settings, which work the same as in any Moodle assignment
