In the same part of the settings there are options for who judges and when:

| Judging Setting | Explanation |
|---|---|
| **Start date for comparisons** | Leave this blank if you want your judges to be able to start making comparisons immediately – e.g. if you are running this as a class-based learning activity<br>Otherwise enable and set a date that allows time for all items being judged to have been added. This is especially important for summative assessments. |
| **Allow judge to make comparisons while their submission is editable** | For a summative assessment you would usually not select this.<br>For learning activities we recommend that you do select this. It will 1) enable students to start making comparisons before all submissions are finalised and 2) provide flexibility for students to improve their work and resubmit after comparing the efforts of their peers. |
| **Introduction for judges** | Using this text box, enter the assessment criteria that will be the basis of making comparisons in your assessment task. This is likely to be something similar to “Choose the best project pitch” or “Which answer shows better understanding of X?” and so on. |
| **Judges** | Select anyone who you want to act as judges. This would usually be the students and the teaching staff. The specific roles available will be set by your institution. If in doubt, just select all. |
