## Feedback types

This section is general to all assignments, regardless of whether you have used Comparative Judgement.

| Feedback Setting | Explanation |
|---|---|
| **Feedback comments** | If enabled the teacher can leave comments for each submission |
| **Annotate PDF** | If enabled the teacher can create a pdf file to annotate over the top of the students work |
| **Feedback files** | If enabled the teacher can upload feedback files e.g. marked up submissions, a comments document or audio feedback |
| **Offline grading worksheet** | If enabled the teacher will be able to download and upload a worksheet with student grades |
| **Comment inline** | If enabled submission text will be copied into the feedback comment field to enable editing / commenting inline |

Further guidance is available here: <https://docs.moodle.org/502/en/Assignment_settings#Feedback_types>

## Submission settings

This section is general to all assignments, regardless of whether you have used Comparative Judgement.

| Submission Setting | Explanation |
|---|---|
| **Require students to click the submit button** | If you select yes, students will have to click a submit button to indicate that they have finished making any changes to their item and it is ready to be judged. If you select no, students can change their work at any time. |
| **Require that students accept the submission statement** | This may be specific to your institution but if yes is selected, students will be required to accept a statement confirming, for example, that the submission is their own work, and anything based on the work of others has been fully cited. |
| **Allowed attempts** | The maximum number of submission attempts allowed |
| **Grant attempts** | You can select from three options, manually (meaning the teacher must authorise via the Submissions or Grader page), automatically (meaning resubmission is automatically allowed after grading, regardless of grade), or automatically until pass (meaning resubmission is automatically granted if the student has not achieved a passing grade). |

## Group submission settings

The Moodle plugin supports group submission, and as with individuals, groups will not see their own submission when judging.

As with any other Moodle group assignment, you need to start by creating your groups: <https://docs.moodle.org/502/en/Groups>

| Group Setting | Explanation |
|---|---|
| **Students submit in groups** | Select Yes if you want your students to submit in groups |
| **Require all group members to submit** | This setting will only be visible if you previously ticked the "Require students click submit button" earlier. If selected, the assignment will not be classed as "submitted" until all group members have made a contribution. When one student has submitted, the other members of their group will be able to see who still needs to submit. |
| **Grouping for student groups** | If students are changing groups throughout the course then you need to select the groups here for this assignment. If they are staying in their standard groups that you set up at the beginning of the course then ignore this and their groups will automatically be selected. |
| **Require group to make submission** | If you select yes, then students must be in a group to be able to submit. If they are not assigned to a group they will not have the option to submit, |


## Notifications

This section is general to all assignments, regardless of whether you have used Comparative Judgement.

| Notification Setting | Explanation |
|---|---|
| **Notify graders about submissions** | If selected the grader (usually the teacher) will receive notifications regarding every submission, regardless of whether early, on-time or late |
| **Notify graders about late submissions** | If selected the grader (usually the teacher) will receive notifications regarding every late submission |
| **Default for ‘notify student’** | Select yes if you want notify students to be ticked by default when grading. |
