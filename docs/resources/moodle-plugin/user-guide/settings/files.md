In the same part of the settings there are options for the items uploaded for judgement:

| File Setting | Explanation |
|---|---|
| **Maximum number of uploaded files** | If file submissions are enabled, each student will be able to upload up to this number of files for their submission. For most comparative judgement sessions this would be set to 1. |
| **Maximum submission size** | Restrict the maximum submission size to 10MB or less. The larger the submission file sizes, the slower and more data-heavy the **Do comparison** process. |
| **Accepted file types** | Ideally all students should use the same file type for their submissions so we recommend that you limit them to using your preferred format. If submissions are a single page, Moodle presents images files such as jpegs more neatly than pdfs. This lends itself particularly well to students photographing and uploading a sheet of handwritten work. |
| **Word limit** | If you have selected **Online text**, under **Submission types**, then you will now have an option to set a word limit. You may choose to add a word limit, but for comparative judgement it is generally more important to consider how many pages you will allow each student to submit and to make that explicit in your instructions. If you intend to allow students to submit more than one page each then ideally do a few test judgements yourself to check how challenging this will be for the specific task you have set. |
