| Grade Setting | Explanation |
|---|---|
| **Grade** | Choose from Point (a numerical value), Scale (requires you to choose an option from a further drop down list) or None (feedback only). In Comparative Judgement we would usually choose Point.<br>When you choose Point, you must also set the Maximum Grade. We recommend that you use the default Maximum Grade of 100. |
| **Grading method** | The default is simple direct grading. Use the default for Comparative Judgement assignments. |
| **Grade category** | This controls the category in which grades are placed in the gradebook |
| **Grade to pass** | This sets the minimum grade required to pass |

> **Note:** After you have sent grades to the gradebook, you can still go back and rescale your grades but at that point you cannot change the grade type.
