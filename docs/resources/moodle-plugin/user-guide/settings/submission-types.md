At the start of this section, you will see 5 tick-boxes:

| Tick Box | Explanation |
|---|---|
| **Comparative judgement** | Select this to enable comparative judgements. |
| **File submissions** | Most assignments are files submissions so you will probably want to leave this selected. |
| **Online text** | Select this if you want student to directly type their submission into a text box. |
| **Allow comparison of pairs of exemplars** | Select this if you plan to upload your own carefully selected examples for comparison. This has two main purposes: 1) you can add some high standard examples to ensure that students get to see some best practice within their comparisons, 2) you can seed some already graded submissions from a previous year to help you identify grade boundaries within the new submission pool. |
| **Enable repeat comparisons** | Select this to ensure students can continue comparing even after all possible pairings of submissions have been judged. |

Next you have options regarding the number of judgements required

| Setting | Explanation |
|---|---|
| **Minimum comparisons per judge** | For summative assessments, you must ensure a minimum of 10 comparisons per submission. Assuming every judge is a student who also submitted an item for judging, then you should set a minimum 10 comparisons per judge as standard.<br>For learning activities we generally also suggest a minimum of 10 comparisons per judge but this can be flexible depending on the size and nature of the submissions. We recommend that you test judging some items for yourself to get a feel for what would be an appropriate number to enable the intended learning. |
| **Maximum comparisons per judge** | For learning activities you may have no upper limit in mind. If so this can be left blank.<br>For summative assessments, the maximum comparisons will usually be the same as the minimum comparisons. |
| **Minimum comparisons per submission** | For summative assessments, the research literature recommends 10 comparisons per submission to ensure robust grades. So set this to 10x the total number of submissions. E.g. if 27 students are submitting work for formal assessment then set the minimum comparisons to 270.<br>For learning activities you can leave this blank. |
| **Enable comparison comments** | If selected, this allows judges to make written comments on submissions when doing each comparison. This has two purposes: 1) to encourage students to consider their choices more deeply, 2) to provide students with written feedback on their submissions. Comments do not carry over between pairs but are saved so they can be shared / used later.<br>Bear in mind that adding comments will mean students require longer to complete the comparison activity. If judges will predominantly be judging via mobile phones, then we recommend that you do not enable comparison comments. |

> **Note:** It is recommended that the teacher should also do a series of judgements to ensure you have reviewed most of the work submitted. A rule of thumb is to do at least half as many judgements as there are submissions (as you see two at a time), so that you have seen everything submitted at least once. If you have set a maximum number of judgements, you will need to adjust this before you do your judgements.
