{% include moodle-guide-draft.html %}

This button appears if **Enable comparison comments** is selected in the **Submission Types** settings (see [Submission types and comparisons](/resources/moodle-plugin/user-guide/settings/submission-types.html)). Here you can view comments submitted by judges.

To distribute the comments to students, click the Import comments button at the bottom of the screen.

The comments will appear to the students in the “Feedback comments” when students visit their submission.

If there is already a comment against the submission then the copied comment gets appended to it.

Consider reviewing comments before distributing to ensure they are fair and appropriate.
