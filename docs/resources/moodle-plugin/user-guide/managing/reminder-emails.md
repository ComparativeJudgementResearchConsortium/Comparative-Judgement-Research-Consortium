title: Manage comparison request emails
---

{% include moodle-guide-draft.html %}

If judgements will be done remotely, you can use this feature to send emails informing or reminding judges to start or complete their comparisons.

Remember the dates automatically published to students at the outset regarding the assignment, relate only to the item(s) they must submit to be judged. You must communicate the dates judging will happen separately.

Where possible, we suggest arranging for judgements to be done in class. This enables you to manage the process, make sure it is clear, and ensure all judgements are done at the same time.
