You can add exemplar submissions that will be included when judges do comparisons.

- These might be examples of high-quality submissions that you wish your students to be exposed to when doing judging.
- They might be submissions that represent grade boundaries that you later use to assign grades to students work, and to ensure standards are maintained across cohorts.
- Exemplars can also be used just to enable you to test the judging experience, and can be deleted if you wish before the assignment is available to your students.

To use exemplars, first tap the button **Add exemplar**:

| Add Exemplar Setting | Explanation |
|---|---|
| **Title** | Give each exemplar a unique title |
| **File submissions** | If you have opted to allow file submissions you can upload pre-prepared exemplars in a format of your choosing. Jpegs work particularly well. Each exemplar must be uploaded individually. |
| **Online text** | If you have opted to allow online text, you can directly type your exemplars. This can work well for demonstrations and short learning tasks, e.g. comparing project abstracts. The online text box also allows you to add images. |
| **Save changes** | After adding each exemplar you must save. The save changes button will save your latest exemplar and then finish. Use this when you have added your final exemplar or if you want to take a break and check what you have uploaded so far. |
| **Save changes and add another** | If you have additional exemplars to save, choose save changes and add another. Repeat this as many times as required. It is recommended that all exemplars are the same file type if possible. |
| **Cancel** | This will navigate you away from the add exemplar screen. |
