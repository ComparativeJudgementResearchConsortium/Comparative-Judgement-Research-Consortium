For many students, using comparative judgement will be new and it is important to introduce the concept before running the practical session. Explain the "why" before the "how".

Students are used to rubrics and marks, so a task with neither can feel unusual at first. A short, plain-language explanation helps, e.g.: *You'll see two pieces of work, choose which is better overall, and repeat this several times with different pairs. Many judgements from many people are combined into a rank order. Due to the maths behind this process, even if there is some variation in the decisions made, the overall collective ranking will be valid and reliable.*

> **Note:** No More Marking have a colour sorting demo which provides an excellent hands-on introduction to the concept of comparative judgement: <https://www.nomoremarking.com/demo?countryCode=GB>

If you plan for students to work in pairs and/or to participate in class discussion then it is also worth warming the class up to that if it is not their normal way of working in lectures.

## What they will see

When the students log in to the live assignment they will see a button to add a submission

![The student view with the Add submission button](/images/moodle-plugin/user-guide/student-add-submission.png)

If you have set judging to open at a later time / date then after submitting they will just see options to edit and remove their submission, which will remain available while the assignment is still open.

![The student view with buttons to edit or remove a submission](/images/moodle-plugin/user-guide/student-edit-remove-submission.png)

If you have set judging to be open while assignments are still editable, then those edit buttons will remain once judging has started, and the students will also see the **Do comparison** button.

![The student view with the Do comparison button](/images/moodle-plugin/user-guide/student-do-comparison-button.png)

When the students click **Do comparison**, they will see the judging instructions at the top of the page and the number of judgements they need to do. This progress counter will count down until the minimum number of judgements is completed. If you have set a maximum number of judgements per student then judging will automatically end when they reach that number. If you have set up the assignment to allow the students to do extra judgements, then the counter will switch once the minimum threshold is reached, to show how many judgements they have completed in total. 

![Judging instructions shown at the top of the comparison page](/images/moodle-plugin/user-guide/judging-instructions.png)

Below the instructions, the students will see the first pair of submissions to judge. They will never be presented with their own submission. They may see the same submissions more than once, but in different pairs.

![A pair of items to judge](/images/moodle-plugin/user-guide/judging-pair.png)

If you selected **Enable comparison comments** in the **Submission types** settings, then the students will see comment boxes immediately below the submissions to be judged, with the selection buttons (**Choose A** / **Choose B**) available at both the top and bottom of the page. It is recommended that you advise the students that any comments they make may be passed anonymously to their peers as feedback, but will be reviewed by you first.  

![Comment boxes and the Choose A / Choose B buttons](/images/moodle-plugin/user-guide/comment-boxes.png)

As soon as a selection button is clicked, the next pair will appear, with new blank comment boxes. Comments relate to the specific paired comparisons made and do not carry over if the same individual submission is seen more than once. You will be able to collate all comments after judging has completed and may want to advise the students that they do not need to repeat the same feedback for the same submission if seen more than once, but can add additional comments if they wish to. 

![The next pair of items to judge](/images/moodle-plugin/user-guide/next-pair.png)

![Comment boxes and the Choose A / Choose B buttons](/images/moodle-plugin/user-guide/comment-boxes.png)
